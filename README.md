# السبورة الذكية — Smart Classroom Board

سبورة بيضاء تفاعلية بسيطة، بواجهة عربية RTL، مخصّصة للمدرّسين والمدارس والسناتر التعليمية. تعمل داخل المتصفح مباشرة على الكمبيوتر والتابلت والموبايل، وتدعم الماوس واللمس وقلم الشاشات اللمسية (بما فيها ضغط القلم عند توفره).

## التشغيل محليًا

يتطلب [Node.js](https://nodejs.org) نسخة 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يظهر في الطرفية (عادة `http://localhost:5173`).

### أوامر أخرى

```bash
npm run build   # بناء نسخة الإنتاج في مجلد dist/
npm run preview # معاينة نسخة الإنتاج المبنية
npm run lint    # فحص جودة الكود (oxlint)
npm run test    # تشغيل الاختبارات (vitest)
```

## المزايا

- **رسم وكتابة حرة**: قلم وهايلايتر بجودة خط طبيعية باستخدام مكتبة [`perfect-freehand`](https://github.com/steveruizok/perfect-freehand)، مع دعم ضغط القلم على الأجهزة التي توفره، وتنعيم حركة الماوس بمكتبة [`lazy-brush`](https://github.com/dulnan/lazy-brush).
- **أدوات أساسية فقط**: قلم، هايلايتر، ممحاة، ألوان، تحكم بسُمك الخط، تراجع/إعادة، مسح السبورة، تحديد/تحريك/تحجيم/حذف.
- **صفحات متعددة**: إضافة صفحات جديدة والتنقل بينها بسهولة.
- **عناصر تعليمية جاهزة**: مكتبة أشكال ورموز مقسّمة حسب المادة (رياضيات، فيزياء، كيمياء، علوم، جغرافيا، عربي وإنجليزي) يمكن إضافتها للسبورة وتحريكها وتكبيرها/تصغيرها وحذفها.
- **حفظ تلقائي محلي**: كل ما يُرسم يُحفظ تلقائيًا في متصفح الجهاز (IndexedDB) دون الحاجة لحساب أو اتصال بالإنترنت، ويُستعاد تلقائيًا عند تحديث الصفحة.
- **سبورة جديدة**: إنشاء سبورة/درس جديد بضغطة واحدة.
- **تصدير**: تصدير الصفحة الحالية كصورة PNG، أو الدرس كاملًا (كل الصفحات) كملف PDF واحد.
- **استجابة كاملة**: تصميم يعمل بسلاسة على الكمبيوتر والتابلت (iPad وAndroid) والموبايل والشاشات الذكية.

## البنية التقنية (Stack)

- **React + TypeScript + Vite** — واجهة سريعة وقابلة للتطوير.
- **Tailwind CSS** — تنسيق بسيط وسريع مع دعم كامل لـ RTL.
- **Canvas 2D API** مع مساحة إحداثيات منطقية ثابتة (1600×1000) لضمان تطابق الرسم بين كل الأجهزة، وطبقتين (قاعدة + طبقة حيّة) لأداء رسم سلس أثناء الكتابة.
- **IndexedDB** (عبر `idb-keyval`) للحفظ التلقائي المحلي.
- **jsPDF** لتصدير الدروس كملفات PDF.
- **Vitest** لاختبارات الوحدة على منطق التراجع/الإعادة، محرّك الرسم، مكتبة العناصر التعليمية، والتخزين.

هذا المشروع مستقل تمامًا حاليًا (بدون حسابات مستخدمين أو خوادم خلفية)، لكن بُني بأسلوب منظم (فصل الحالة/العرض/التخزين) يسهّل تطويره لاحقًا إلى SaaS أكبر (حسابات، مزامنة سحابية، مشاركة دروس، إلخ).

## المشاريع مفتوحة المصدر التي استُفيد منها

لم يُنسخ كود من أي من هذه المشاريع، وإنما استُخدمت كمرجع للأفكار أو كمكتبات مباشرة مع الالتزام بتراخيصها:

| المشروع | كيف استُخدم | الترخيص |
|---|---|---|
| [perfect-freehand](https://github.com/steveruizok/perfect-freehand) | مكتبة مثبّتة (npm) لحساب مسار الخط الطبيعي من نقاط القلم/اللمس، تُستخدم مباشرة في `src/lib/strokeRenderer.ts` | MIT |
| [lazy-brush](https://github.com/dulnan/lazy-brush) | مكتبة مثبّتة (npm) لتنعيم حركة الفرشاة عند الرسم بالماوس، تُستخدم في `src/hooks/useDrawing.ts` | MIT |
| [xsukax Smart Board](https://github.com/xsukax/xsukax-Smart-Board) | مرجع لفكرة سبورة بيضاء بسيطة بأدوات أساسية (قلم/ممحاة/ألوان/تصدير) دون نسخ أي كود أو أصول | حسب ترخيص المشروع الأصلي (راجع مستودعه) |
| [OpenBoard](https://github.com/OpenBoard-org/OpenBoard) | مرجع لأفكار عامة حول السبورات التعليمية (تصنيف العناصر حسب المادة) فقط، دون نقل أي كود أو تعقيد الواجهة | GPL-3.0 (لم يُستخدم أي كود منه في هذا المشروع) |

جميع أيقونات ورسومات "العناصر التعليمية" (الأشكال الهندسية، الذرة، الدائرة الكهربائية، إلخ) رُسمت كملفات SVG أصلية خصيصًا لهذا المشروع، ولم تُنسخ من أي مصدر خارجي.

## هيكل المشروع

```
src/
  components/     مكوّنات الواجهة (شريط الأدوات، لوحة الرسم، مكتبة العناصر، التصدير...)
  hooks/          منطق التفاعل (الرسم بالقلم، حالة السبورة)
  lib/            منطق مستقل عن React (الرسم، التخزين، التصدير، إدارة التراجع/الإعادة)
  data/           بيانات مكتبة العناصر التعليمية
  types.ts        أنواع البيانات المشتركة
```
